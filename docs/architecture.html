Qwen Cloud

alibaba dashscope · one key, one seam

every model call — text, image, voice, video — runs here.

qwen3.7-max script qwen3.7-plus agents wan2.7-image-pro images 4K qwen-image-edit-plus edits qwen3-tts voice HappyHorse / Wan 2.7 video
◆ one seam. mock ⇄ real is a single env flag per provider, so ~236 tests and the full demo run offline, then flip to live qwen cloud for production.
◆ best-of-N + dailies. each shot renders several takes; an AI review auto-selects the winner — surfaced as a trace chip, “picked best of 3.”
◆ async by design. video is submit→poll; one always-on reconciler ingests results and streams progress over SSE — no leader election, single instance.
◆ continuity. keyframe-first chaining holds cast & look across independently generated shots; the director chat revises any stage in natural language.
